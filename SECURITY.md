# Security Policy

## Pre-release status

RedmineOH is currently a pre-release project. No promise of production security support is made at this stage.

## Reporting a vulnerability

Do not publish vulnerabilities, credentials, customer data, operational screenshots, or sensitive environment details in public issues or public pull requests.

Until a company-owned security contact is established, report security concerns privately to:

`<PRIVATE_SECURITY_CONTACT_TO_BE_DEFINED>`

If that contact is not yet available, coordinate privately with the current repository maintainers and avoid public disclosure.

## Supported versions

Supported-version policy has not been formalized yet. Treat the active default branch as under development and verify any fixes case by case.

## Data handling

Remove customer, operational, and environment-specific data from any report, reproduction steps, logs, screenshots, uploads, or attachments before sharing them.
