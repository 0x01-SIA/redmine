# Security Policy

## Pre-release status

RedmineOH is currently a pre-release project. No promise of production security
support is made at this stage.

## Reporting a vulnerability

Do not publish vulnerabilities, credentials, customer data, operational
screenshots, or sensitive environment details in public issues or public pull
requests.

RedmineOH does not yet have a dedicated company-owned security mailbox.

Until one is established, report security concerns privately to the current
repository maintainers using a non-public channel. Prefer a private repository
security advisory or other direct maintainer contact. If no private reporting
channel is available yet, stop and obtain one before sharing any sensitive
details.

## Supported versions

Supported-version policy has not been formalized yet. Treat the active default
branch as under development and verify any fixes case by case.

## Data handling

Remove customer, operational, and environment-specific data from any report,
reproduction steps, logs, screenshots, uploads, or attachments before sharing
them.
