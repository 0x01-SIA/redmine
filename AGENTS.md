# Project Workflow Memory

## Redmine Task Workflow

When working on Redmine issues for this project:

1. Open the Redmine issue and read the task description/instructions there.
2. Keep all working notes, analysis, draft comments, and discussion in the Codex app chat.
3. Do not post intermediate comments to Redmine.
4. Publish only the final, user-ready comment on the Redmine issue.
5. When the task is complete, set the issue assignee to `0x01 SIA`.
6. When the task is complete, set the issue status to `Feedback`.

This workflow applies across chats in this project unless the user explicitly overrides it.
